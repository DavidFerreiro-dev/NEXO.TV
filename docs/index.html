NEXO.TV Documentation

Technical documentation for the NEXO.TV static movie catalog.

Last updated: November 12, 2026

Overview

NEXO.TV is a static web application for browsing and playing a curated movie catalog. The catalog is managed in Google Sheets and enriched with movie metadata from TMDB.

External media and legal scope

NEXO.TV is a public index and interface, not a host for third-party movies. Movies are linked from Internet Archive; in cases involving NEXO.TV original works, audiovisual files may be hosted on external services such as Hugging Face. NEXO.TV only crosses TMDB data with those external URLs.

TMDB integration

The Netlify function calls the TMDB movie endpoint with Spanish localization and credits:

/3/movie/{id}?language=es-ES&append_to_response=credits

It returns:

  • Title, poster and landscape image
  • Rating, release date and runtime
  • Year and genres
  • Director and cast
  • Production companies and countries

Data priority is:

  1. Non-empty values from the Google Sheet.
  2. TMDB values for missing fields.
  3. Video metadata for duration when TMDB has no runtime.

Rating and release date fields are hidden when no value is available.

Reference: TMDB API documentation.

Frontend behavior

  • The loading screen remains visible while the catalog and TMDB data are being loaded.
  • Favorites and Continue Watching use browser localStorage.
  • There is no account or user synchronization system.
  • Essential, Original and Academy Awards filters are controlled by spreadsheet fields.
  • Must See cards and Must See artwork are no longer used.
  • Videos are hosted externally, including Internet Archive and Hugging Face.

Deployment

Netlify hosts the static site and the serverless TMDB function.

Environment variable

Configure this variable in Netlify. Do not put the token in frontend files.

TMDB_READ_TOKEN=YOUR_TMDB_READ_TOKEN

CLI commands

cd "C:\Users\david\OneDrive\Documentos\ReposPersonales\NEXO.TV"
netlify login
netlify link
netlify env:set TMDB_READ_TOKEN "YOUR_TOKEN"
netlify deploy --prod

Local development:

netlify dev

Function test:

/.netlify/functions/tmdb?ids=558

References: Netlify Functions · Netlify dashboard.
